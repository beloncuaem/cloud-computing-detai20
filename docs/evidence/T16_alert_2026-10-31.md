# T16 — Cảnh báo giải mã bất thường (31/10/2026)

Bản ghi terminal để đưa vào báo cáo. Đây **chưa phải ảnh chụp màn hình**; khi nộp cần chụp lại terminal/ảnh kết quả theo quy ước `docs/evidence/`.

## Môi trường

- Windows, Docker Engine 29.7.2, Docker Compose v5.4.0.
- Stack dự phòng: PostgreSQL 16 + Vault 1.20 (dev mode) + API FastAPI, chạy bằng `docker compose up -d --build`.
- k6 `grafana/k6:0.54.0`; analyzer chạy bằng `python:3.12-slim`.
- Ngưỡng: **200 request `transit/decrypt` / 60 giây / một danh tính**.

## 1. Tải nền 10 phút (false-positive)

Lệnh:

```powershell
docker run --rm -v "${PWD}:/work" -w /work grafana/k6:0.54.0 run `
  -e BASE_URL=http://host.docker.internal:8000 `
  -e API_KEY=local-demo-api-key-change-me `
  -e VUS=5 -e SLEEP=2 -e DURATION=10m bench/k6/mixed.js
```

Kết quả k6:

- 1.478 HTTP request, 2,456 request/giây, 0 lỗi (0,00%).
- p95 = 51,91 ms; p99 = 95,52 ms; 1.477 iteration hoàn tất.
- 5 VUs, `SLEEP=2`; audit ghi nhận **469** request `transit/decrypt` từ danh tính `approle` trong 10 phút (~47/phút).

Phân tích audit:

```text
OK    identity=approle requests=469 threshold=200/60s

No identity exceeded the threshold.
EXIT=0
```

Kết luận: tải bình thường không gây false positive.

## 2. Gieo 200 lần giải mã (true-positive)

Lệnh:

```powershell
docker compose run --rm --no-deps vault-init python scripts/generate_decrypt_load.py --count 200
```

Kết quả:

```text
Generated 200 decrypt requests in 0.36s (~33607 requests/minute) using the demo token identity.
```

Phân tích audit:

```text
OK    identity=approle requests=469 threshold=200/60s
ALERT identity=token requests=200 threshold=200/60s first_seen=2026-10-31T13:09:54.552214+00:00 threshold_reached=2026-10-31T13:09:54.907294+00:00 latency=0.4s

1 identity/identities exceeded the threshold.
EXIT=2
```

Kết luận: burst 200 giải mã bị phát hiện trong 0,4 giây; danh tính `token` tách khỏi `approle` của ứng dụng.

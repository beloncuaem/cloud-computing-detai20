# T13 — TLS và bảo vệ at rest (trạng thái 31/10/2026)

**Kết luận: CHƯA ĐẠT.** Đây là phần việc của SV1 (Vault file storage + TLS + reverse proxy). Stack dự phòng hiện chạy Vault dev mode và API qua HTTP, nên không được ghi T13 là đã vượt qua.

## Phần đã kiểm tra được

Không có secret trong image API:

```text
$ docker run --rm detai20-api:local sh -c \
    "find /app -maxdepth 3 \( -name '.env' -o -name 'vault-credentials.json' \) -print"
(không có kết quả; exit 0)
```

`vault-credentials.json` chỉ nằm trong volume `/credentials`, không nằm trong image.

PostgreSQL chưa bật TLS:

```text
$ docker exec detai20-postgres-1 psql -U postgres -d encryption_db -c "SHOW ssl;"
 ssl
-----
 off
(1 row)
```

Máy lab: Windows 11 Home, AMD Ryzen 9 7940HS, 16 GB RAM. Truy vấn BitLocker bằng tài khoản thường bị `Access denied` và báo `C: does not have an associated BitLocker volume`, nên **không kết luận** được trạng thái mã hóa ổ đĩa; cần chạy lại bằng PowerShell quản trị.

## Còn thiếu để đạt T13

- Vault chạy file storage, TLS 1.2+ với chứng chỉ lab; `https://localhost:8200/v1/sys/health`.
- Reverse proxy TLS cho API (ví dụ 8443) và `curl -k https://localhost:8443/health`.
- PostgreSQL TLS (`SHOW ssl = on`) hoặc ghi rõ ngoại lệ.
- Xác nhận BitLocker/volume encryption bằng quyền quản trị, ghi rõ VHDX Docker Desktop nằm trên ổ đã mã hóa.

Khi SV1 hoàn thành, chạy lại các lệnh trong `docs/testing/test-plan.md` mục T13 và chụp ảnh.

## T11 — Gitleaks và kiểm tra secret trong lịch sử

Quét toàn bộ lịch sử bằng đúng image và config của CI ([`.github/workflows/security-gate.yml`](../../.github/workflows/security-gate.yml)):

```text
$ docker run --rm -v "<repo>:/repo" ghcr.io/gitleaks/gitleaks:v8.24.0 detect \
    --source=/repo --config=/repo/.gitleaks.toml --log-opts="--all" --redact --verbose
1:21PM INF 14 commits scanned.
1:21PM INF scanned ~146019 bytes (146.02 KB) in 1.91s
1:21PM INF no leaks found
exit=0
```

Kiểm tra ignore và file được track:

```text
$ git check-ignore -v .env student2_project_windows/.env student2_project_windows/vault-credentials.json
.gitignore:2:.env                                          .env
student2_project_windows/.gitignore:1:.env                  student2_project_windows/.env
student2_project_windows/.gitignore:12:vault-credentials.json  student2_project_windows/vault-credentials.json

$ git ls-files | grep -E '(^|/)\.env$|vault-credentials\.json|vault-init\.json'
(none)
```

Kiểm chứng dương tính: gieo một token GitHub giả vào thư mục tạm ngoài repo rồi quét bằng cùng config:

```text
$ docker run --rm -v "<repo>:/repo" -v "<tmp>:/scan" ghcr.io/gitleaks/gitleaks:v8.24.0 \
    dir /scan --config=/repo/.gitleaks.toml --redact --verbose
Finding:     GITHUB_TOKEN=REDACTED
RuleID:      github-pat
File:        /scan/fake.env
1:22PM WRN leaks found: 1
exit=1
```

Kết luận: lịch sử hiện tại 0 leak; `.env` và `vault-credentials.json` bị ignore và không được track; cùng config vẫn phát hiện secret giả (H3). Secret giả chỉ nằm trong thư mục tạm, đã xóa, không đưa vào Git.

## T01 — Envelope encryption round-trip

Tạo bản ghi:

```text
POST /records -> 201
{"id":"f36b43b2-320f-4448-bf8a-1876c9e16d39","record_type":"customer_phone",
 "status":"encrypted_and_stored","created_at":"2026-10-31T13:21:16.145724Z"}
```

Đọc lại và metadata:

```text
GET /records/f36b43b2-... -> 200
{"id":"f36b43b2-...","record_type":"customer_phone","value":"0901234567",
 "created_at":"2026-10-31T13:21:16.145724Z"}

GET /records/f36b43b2-.../metadata -> 200
{"id":"f36b43b2-...","record_type":"customer_phone","ciphertext_bytes":26,
 "kek_name":"app-data-key","kek_version":1,...}
```

Kiểm tra bảng lưu trữ:

```text
 record_type    | ciphertext_bytes | nonce_bytes |  dek_prefix  |   kek_name   | kek_version
----------------+------------------+-------------+--------------+--------------+-------------
 customer_phone |               26 |          12 | vault:v1:ne8 | app-data-key |           1
```

Kết luận: POST 201, GET trả đúng plaintext, ciphertext 26 byte, nonce 12 byte, `encrypted_dek` mang prefix `vault:v1:` và `kek_version = 1`. Bảng `sensitive_records` không có cột plaintext.

## T05 — Xác thực API key và admin key

```text
GET /records (không key)                  -> 401 {"detail":"Missing or invalid API key"}
GET /records (X-API-Key: wrong-key)       -> 401 {"detail":"Missing or invalid API key"}
POST /admin/rotation/transit-key
     (X-API-Key hợp lệ, không có admin key) -> 403 {"detail":"Missing or invalid administrator key"}
```

Kết luận: thiếu/sai API key bị 401; dùng API key thường cho endpoint quản trị bị 403 (đúng `require_admin_key`). Không gọi xoay khóa trong ca này.

## T07 — Audit log của Vault

```text
$ docker exec detai20-vault-1 sh -c "VAULT_ADDR=http://127.0.0.1:8200 VAULT_TOKEN=root vault audit list"
Path     Type    Description
----     ----    -----------
file/    file    n/a
```

Ba dòng cuối của `transit/decrypt` (đã cắt chuỗi, token bị Vault băm):

```json
{"auth":{"accessor":"hmac-sha256:612b...","client_token":"hmac-sha256:be2f...","display_name":"approle",...
```

Ba dòng cuối của `database/creds`:

```json
{"auth":{"accessor":"hmac-sha256:0460...","client_token":"hmac-sha256:5fe1...","display_name":"token",...
```

Đếm plaintext của bản ghi T01 trong audit:

```text
$ grep -a -c '0901234567' /tmp/vault-audit.log
0
```

Kết luận: audit file device đang bật; có request `transit/decrypt` từ AppRole và `database/creds` từ token operator; plaintext không xuất hiện trong audit. Token/accessor đều ở dạng HMAC.

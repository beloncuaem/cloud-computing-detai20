## 1. D-05 — `vault_admin` không còn SUPERUSER

### 1.1. Mã nguồn đối chiếu

File: `api/sql/00-create-roles.sql`, dòng 27–49

```sql
-- Least privilege for the Vault database plugin (D-05).
-- CREATEROLE: create and drop the dynamic login roles it owns.
-- NOINHERIT: membership in app_writer does not give this role table access.
-- NOSUPERUSER / NOCREATEDB: cannot bypass grants or create databases.
DO $$
BEGIN
    IF NOT EXISTS (SELECT 1 FROM pg_roles WHERE rolname = 'vault_admin') THEN
        CREATE ROLE vault_admin
            WITH LOGIN NOSUPERUSER NOCREATEDB CREATEROLE NOINHERIT
            PASSWORD 'local_vault_admin_password';
    ELSE
        ALTER ROLE vault_admin
            WITH LOGIN NOSUPERUSER NOCREATEDB CREATEROLE NOINHERIT
            PASSWORD 'local_vault_admin_password';
    END IF;
END
$$;

GRANT CONNECT ON DATABASE encryption_db TO vault_admin;
GRANT app_writer TO vault_admin WITH ADMIN OPTION;
```

### 1.2. Lệnh kiểm tra quyền (chạy trên stack Docker)

```powershell
docker compose exec -T postgres psql -U postgres -d encryption_db -c "
  SELECT rolname, rolsuper, rolcreatedb, rolcreaterole, rolinherit
  FROM pg_roles
  WHERE rolname = 'vault_admin';"
```

Kỳ vọng:

| rolname | rolsuper | rolcreatedb | rolcreaterole | rolinherit |
|---|---|---|---|---|
| vault_admin | f | f | t | f |

### 1.3. Kiểm tra vault_admin không đọc được bảng dữ liệu

### 2.3. Connection không giữ khi gọi Vault

File: `api/app/routes/records.py`:

**create_record** (dòng 43–95): Gọi Vault `encrypt_sensitive_value()` TRƯỚC khi mở `session_scope()`. Comment dòng 45–46: `# Vault runs before a connection is checked out so the pool is not held for the Transit round trip (D-08).`

**read_record** (dòng 137–194): Đọc row trong `session_scope()` đầu tiên → đóng session → gọi Vault `decrypt_sensitive_value()` NGOÀI session → mở `session_scope()` mới ghi audit.

Cả hai endpoint đều không giữ DB connection trong lúc chờ Vault phản hồi.

### 2.4. DEK Cache cho cấu hình D'

File: `api/app/services/encryption.py`, class `DekCache` (dòng 21–63):

- Mặc định **tắt** (`DEK_CACHE_TTL_SECONDS=0`) để T08 `min_decryption_version` có hiệu lực mỗi lần decrypt.
- Bật bằng `DEK_CACHE_TTL_SECONDS=120`: mỗi wrapped DEK đã unwrap được cache 120 giây, các lần đọc tiếp theo cùng bản ghi bỏ qua roundtrip Vault → giảm latency.
- LRU eviction khi vượt `DEK_CACHE_MAX_ENTRIES` (default 1024).
- Thread-safe (dùng `threading.Lock`).

File: `docker-compose.yml`, dòng 20–22:

```yaml
# 0 keeps T08 honest. Set 120 (or higher) only when measuring configuration D'.
DEK_CACHE_TTL_SECONDS: "${DEK_CACHE_TTL_SECONDS:-0}"
DEK_CACHE_MAX_ENTRIES: "${DEK_CACHE_MAX_ENTRIES:-1024}"
```

### Kết luận D-08: **ĐẠT**

Pool 20+20, 2 worker, connection không giữ khi gọi Vault. DEK cache code sẵn sàng cho cấu hình D'.
